# Simon Game

A simple browser-based Simon memory game built with HTML, CSS, and JavaScript.

## How to play

1. Open `index.html` in a web browser.
2. Press any key to start the game.
3. Watch the highlighted color, then click the matching button.
4. Repeat the full sequence as it grows by one color each round.
5. If you click the wrong color, the game ends. Press any key to start a new game.

The highest score is tracked for the current page session.

## Project files

- `index.html` — game layout and buttons
- `style.css` — appearance and button flash effects
- `app.js` — sequence generation, input handling, and scoring

## Requirements

No installation or external dependencies are required. Open `index.html` directly in a modern browser.
